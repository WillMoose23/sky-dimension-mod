# 1.0.2 Preset load

Deleting a world reloads world-generation registries. Stacked Dimension 1.0.1 crashed there because its generator read `stackedworld:overworld` noise settings while that registry entry was still unbound.

1.0.2 keeps the noise settings as a reference and builds the island generator only after registries have finished loading. The sky-island settings from 1.0.1 are unchanged.
