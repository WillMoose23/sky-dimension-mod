# 1.0.14 LevelReader interface mixin fix

Version **1.0.14**. Fixes a launch crash on Minecraft 26.3 where Fabric failed during mixin PREPARE before the game started.

## What changed

`LevelReaderBiomeMixin` was declared as `public abstract class` with `@Mixin(LevelReader.class)`. On 26.3, `LevelReader` is an interface; Mixin only allows class-style mixins on classes. That produced `InvalidMixinException: @Mixin target type mismatch` and blocked startup (Sodium preLaunch appeared in the stack trace as a side effect).

The mixin is now `public interface LevelReaderBiomeMixin`, matching Fabric API’s pattern for `LevelReader` hooks. Behavior of the `getNoiseBiome` injection is unchanged.
