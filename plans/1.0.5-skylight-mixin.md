# 1.0.5 Skylight mixin crash

Version **1.0.5**. Fixes the world-load crash in 1.0.4: `SkyLightEngineMixin` could not apply because it shadowed `enqueueDecrease(JJ)V` on `SkyLightEngine`.

## Cause

`enqueueDecrease`, `enqueueIncrease`, and `getState` are declared on `LightEngine`, not `SkyLightEngine`. `storage` and `chunkSource` are fields on `LightEngine` as well. Mixin 0.8.7 looks up `@Shadow` members only on the target class, so transforming `SkyLightEngine` failed before the integrated server finished creating levels.

## Change

Those parent members are reached through `LightEngineInvoker` (`@Invoker` / `@Accessor` on `LightEngine`). Shadows that really live on `SkyLightEngine` (`mutablePos`, `crossedSectionEdge`) stay as shadows. Lighting behavior from 1.0.4 is unchanged.

## Limits

- This build writes temporary debug lines while the crash fix is checked. They are removed after the world loads successfully.
- Existing chunks still keep old terrain, lava, and saved skylight until regenerated or relit.
- ScalableLux still constructs its own light engine after the vanilla `SkyLightEngine` class loads. This release only makes that class load.
