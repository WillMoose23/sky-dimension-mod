# 1.0.6 Skylight local capture

Version **1.0.6**. 1.0.5 loaded, then crashed while applying `SkyLightEngineMixin`.

## Cause

`propagateIncrease(long fromNode, long increaseData, int fromLevel)` has two `long` arguments. `@Local(argsOnly = true) long` on `stacked$skyFloorOpacity` found both and refused to pick one. The same capture is on the shape and decrease wraps, which target methods that also take two longs.

## Change

Those captures use `@Local(argsOnly = true, ordinal = 0)`, the first long argument (`fromNode`). The parent-class invoker from 1.0.5 stays.

## Limits

- Temporary debug lines are still written until this load is confirmed.
- Existing chunks keep old terrain, lava, and saved skylight until regenerated or relit.
