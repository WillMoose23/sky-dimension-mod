# 1.5.11 Fabric 26.3

Version **1.5.11** (bugfix bump from 1.5.10). The Aether project at `The-Aether-1.21.1-1.5.10-neoforge` was switched from NeoForge to a Fabric Loom build aimed at Minecraft **26.3**. The Java source was not ported, and `./gradlew compileJava` does not produce a jar.

## What changed

The Gradle project now follows the official Fabric example mod for Minecraft 26.3 (`FabricMC/fabric-example-mod` branch `26.3`, read 2026-10-08):

- Minecraft `26.3` (calendar version, not `1.26.3`)
- Fabric Loader `0.19.5`
- Fabric API `0.161.0+26.3`
- Fabric Loom `1.18-SNAPSHOT` (`net.fabricmc.fabric-loom`, the unobfuscated plugin)
- Gradle `9.7.1`
- Mappings: Mojang official names. Minecraft 26.1+ is unobfuscated, so there is no Yarn mappings dependency. Loom rejected an access widener namespace of `named` and required `official`.

The Fabric announcement for 26.3 (https://fabricmc.net/2026/09/15/263.html, 2026-09-15) said Loom 1.17 and Gradle 9.6.0 at release, with Loader 0.19.5. The example-mod branch has moved forward since that post; this build uses the example-mod pins.

Also added:

- `src/main/resources/fabric.mod.json` (mod id `aether`, entrypoints `com.aetherteam.aether.Aether` and `com.aetherteam.aether.client.AetherClient`)
- `src/main/resources/aether.accesswidener` (converted from `META-INF/accesstransformer.cfg`)
- Mixin config `compatibilityLevel` set to `JAVA_25`, and the NeoForge refmap entry removed
- `mod_version` set to `1.5.11`

`neoforge.mods.toml` is no longer generated into the jar. The template file is still on disk. CurseForge and Modrinth publish plugins were dropped with the NeoForge build.

## Limits

No Fabric jar was built. `./gradlew compileJava` stops at the compiler cap of 10,000 errors. The previous mod was NeoForge 21.1.72 for Minecraft 1.21.1 (797 Java files). About 321 of those files import NeoForge, Nitrogen, Accessories, Cumulus, JEI, or REI. None of Nitrogen, Cumulus, or Accessories is published for Fabric on Minecraft 26.3, and the mod cannot run without them (accessory slots, boss rooms, block-state recipes, synced attachments).

Minecraft 26.3 also removed or renamed APIs this code calls directly:

- `ResourceLocation` is now `Identifier` (`net.minecraft.resources.Identifier`).
- `SwordItem`, `PickaxeItem`, `AxeItem`, `ShovelItem`, `HoeItem`, and `ArmorItem` are gone. Tools are `Item` plus `ToolMaterial` / the `Tool` component. Armor is `Item` plus `ArmorMaterial` in `net.minecraft.world.item.equipment`.
- `GuiGraphics` and `MultiBufferSource` are gone. `RenderType` moved to `net.minecraft.client.renderer.rendertype`.
- Worldgen `Feature` is no longer generic, and `ConfiguredFeature` is gone. Configured features live under `worldgen/feature`.
- NBT reads such as `CompoundTag.getDouble` return `Optional`. Entity save/load goes through `ValueInput` / `ValueOutput`.
- NeoForge enum extensions (`Rarity`, `Boat.Type`, `RecipeBookType`, `MobCategory`, `RecipeBookCategories`) have no Fabric equivalent in this tree. `META-INF/enumextensions.json` is unused on Fabric.

Mixins still target 1.21.1 methods and NeoForge classes (`EventHooksMixin`, `ModelBuilderMixin`). They were not retargeted.

There was no existing `aether-1.5.10` jar in the project or in `~/Library/Application Support/minecraft/mods` (that folder only has `stacked_dimension_mod-1.0.10.jar`), so nothing was archived or installed.

In-game behavior was not tested. The mod does not compile, so it cannot be loaded.
