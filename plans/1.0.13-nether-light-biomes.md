# 1.0.13 Nether light, plants, and mob biomes

Version **1.0.13**. Three fixes for the nether band under the stacked overworld (y=-192 through y=-65). The band is still the overworld dimension, not `minecraft:the_nether`.

## 1. Dark caverns

The band uses the overworld dimension type. That type has `ambient_light` 0 and `visual/ambient_light_color` `#0a0a0a`. In 26.3 the lightmap shader's darkest color is that ambient color. Vanilla nether uses ambient color `#302821` (and `ambient_light` 0.1), so a light level of 0 is still bright enough to see. ScalableLux stores real sky and block light, and Sodium samples it through the overworld lightmap, so an unlit nether cavern is pitch black. Raising the dimension's ambient light would also brighten the overworld and the sky.

The client raises the **read** block-light value to 4 for blocks with y < -64 in a stacked column only (minimum y -192 and height 768). Under the overworld lightmap, level 4 is about the same luminance as vanilla nether ambient color. Torches and brighter blocks stay brighter. Stored light is not changed, so server mob checks still see the real level (0 in a dark cavern). Starlight's sky propagation, including the rule that sky islands do not shadow the overworld, is unchanged.

## 2. Overworld plants

Decoration walks every biome stored in the chunk, so overworld biomes from y >= -64 contribute grass, trees, flowers, and cave plants in the same pass as nether biomes.

What was leaking:

- Surface features (grass, flowers, trees) use a heightmap. When a sky island was the top, the overworld surface search continued from y=319 down to y=-192. A column with no solid overworld block, including a shaft, reported a nether floor, and the plant was placed there.
- Heightmaps that were already below y=-64 were left there.
- Nether biomes also list overworld decorations: `brown_mushroom_normal`, `red_mushroom_normal`, and `spring_lava`. Cave plants (`glow_lichen`, `cave_vines`, lush-cave moss, `classic_vines`) start at `above_bottom`, which is shifted to y=-64, and can scan a few blocks into the band.
- If the section biome was still an overworld biome, the biome filter accepted those decorations.

Overworld decorations are no longer placed below y=-64. The surface search stops at y=-64. A non-nether feature is skipped when its position is in the band, and its `setBlock` calls cannot write into the band, so a patch that starts just above the floor cannot spread down. `sky_surface` is exempt: its placement origin is the chunk bottom, and it only edits y >= 321.

Nether features still generate in matching nether biomes: crimson and warped fungi, forest vegetation, roots, nether sprouts, weeping and twisting vines, nylium checks, nether mushrooms (`brown_mushroom_nether`, `red_mushroom_nether`), glowstone, debris, quartz, basalt, blackstone, deltas, and the nether springs.

## 3. Mob biomes

`ChunkGenerator.getMobsAt` takes the spawn list from `NATURAL_MOB_SPAWNS` at the mob's position. That attribute reads the chunk section biome. A section whose palette is still plains (the default for an empty section, or a chunk generated before this band stored nether biomes) supplies an overworld list even at y=-100. The biome source itself already returns a nether biome for block y < -64.

Spawn selection for a stacked column below y=-64 now uses the nether biome from that noise source, not the overworld biome stored on the same chunk. When a nether section is not entirely nether biomes, it is refilled from that source the first time the chunk starts ticking, then saved and sent to the client. `getNoiseBiome` below y=-64 does the same substitution if a read still sees a non-nether biome.

`NaturalSpawner` picks a random Y from the bottom of the column to the surface. A solid block aborts the attempt, so most rolls in a 768-block column never reach a cavern floor. If that random block is inside the nether band and is not already lava or an open floor, the attempt moves to the nearest open floor in the same column, still inside the band. Lava rolls are left alone so striders can spawn. Overworld and sky Y values are not moved. Fortress and other structure spawn overrides still win over the biome list. Piglins and hoglins still do not zombify in the band. The nether light test for monsters is still real brightness <= 7.

## Limits

- Overworld plants already placed in the nether stay until those chunks are regenerated. New chunks do not get them.
- Biome palettes in existing chunks are corrected when the chunk starts ticking. Terrain blocks are not rebuilt. Mob lists follow the nether biome without waiting for a new chunk.
- Cavern brightness appears when the chunk is meshed again (rejoin or leave the area). Stored skylight is not rewritten, so a relight is not required. Distant Horizons can keep a dark far image until its own cache refreshes.
- Cave carvers are still chosen from the biome at block y=0, so the extra tunnels are overworld carvers.
- `spring_lava`, `brown_mushroom_normal`, and `red_mushroom_normal` are overworld decorations and are not placed below y=-64. Crimson and warped forests keep fungi, roots, and vines. Wastes and deltas keep the nether mushroom features.
- Sky-island shape, underside ores, ScalableLux overworld skylight, slider text, and the 1.0.12 portal and structure placement are unchanged. A normal world and `minecraft:the_nether` are unchanged.
