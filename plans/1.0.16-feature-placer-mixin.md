# 1.0.16 FeaturePlacer mixin target fix

Version **1.0.16**. Fixes world creation hanging during chunk feature generation.

## What changed

On Minecraft 26.3, `FeaturePlacer.place(PlacedFeature, RandomSource, BlockPos)` only forwards to a private `place(..., boolean)`. Calls to `Feature.place` live in that private method. `FeaturePlacerMixin` wrapped `Feature.place` on the public three-argument `place`, so the injection matched nothing. MixinExtras then failed when `FeaturePlacer` was first loaded during `applyBiomeDecoration`, which stalled integrated-server world creation.

The wrap now targets the private four-argument `place` method where `Feature.place` is actually invoked.
