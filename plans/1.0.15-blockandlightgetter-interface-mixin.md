# 1.0.15 BlockAndLightGetter interface mixin fix

Version **1.0.15**. Fixes the same class of launch crash as 1.0.14, on the client mixin config.

## What changed

`NetherLightMixin` targeted `BlockAndLightGetter` as an `abstract class`. On Minecraft 26.3 that type is an interface, so mixin PREPARE failed with `InvalidMixinException: @Mixin target type mismatch`. The mixin is now `public interface NetherLightMixin`; the `getBrightness` injection for nether-band visual block light is unchanged.

## Files

- `src/client/java/stackedworld/mixin/client/NetherLightMixin.java`
- `gradle.properties` (`1.0.15`)

## Build

`./gradlew build` succeeded. Installed jar: `~/Library/Application Support/minecraft/mods/stacked_dimension_mod-1.0.15.jar`. Previous jar: `stacked_dimension_mod/archive/1.0.14/stacked_dimension_mod-1.0.14.jar`.

## Limits

None beyond existing 1.0.13 client nether cavern lighting behavior.
