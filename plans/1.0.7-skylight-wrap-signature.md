# 1.0.7 Skylight wrap signature

Version **1.0.7**. 1.0.6 loaded, then crashed while applying `stacked$skyFloorOpacity`.

## Cause

`getOpacity` and `shapeOccludes` are instance methods inherited from `LightEngine`. MixinExtras does not treat those calls as bare `this` calls, so each wrapper must take the `SkyLightEngine` receiver first and pass it to `Operation.call`. The 1.0.6 handlers started with `BlockState`.

## Change

Both wrappers now start with `SkyLightEngine` and forward that receiver into the original call. The static `shouldPropagateInDirection` wrap is unchanged.

## Limits

- Temporary debug lines are still written until this load is confirmed.
- Existing chunks keep old terrain, lava, and saved skylight until regenerated or relit.
