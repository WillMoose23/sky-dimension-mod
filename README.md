# Sky dimension mod (stacked world)

Fabric mod for Minecraft 26.3: a single overworld column with nether band, overworld surface, and sky islands.

Source lives in [`stacked_dimension_mod/`](stacked_dimension_mod/). Version plans are in [`plans/`](plans/).

## Build

```bash
cd stacked_dimension_mod
./gradlew build
```

Jar output: `stacked_dimension_mod/build/libs/stacked_dimension_mod-<version>.jar`.
